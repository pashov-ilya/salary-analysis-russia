# Анализ среднемесячной заработной платы по регионам России (2022–2023)

## Описание проекта

Проект посвящён анализу среднемесячной номинальной заработной платы работников по субъектам Российской Федерации за 2022 и 2023 годы на основе статистических данных Росстата.

Цель исследования – оценить динамику заработной платы, выявить различия между регионами и определить основные тенденции изменения региональных доходов.

## Используемые инструменты

- Python
- Jupyter Notebook

В проекте использованы встроенные средства Python для обработки данных, выполнения расчётов и формирования аналитических результатов. Сторонние библиотеки не требуются.

## Основные этапы работы

- Загрузка и первичная обработка исходных CSV-файлов.
- Очистка данных и формирование единой структуры для хранения показателей за два года.
- Проверка сопоставимости состава регионов в наборах данных за 2022 и 2023 годы.
- Расчёт основных статистических показателей: среднего значения, медианы, минимума, максимума, стандартного отклонения и размаха.
- Сравнение рассчитанных показателей за два года и оценка их динамики.
- Формирование рейтингов десяти регионов с наибольшей среднемесячной номинальной заработной платой за каждый год.
- Интерпретация результатов и формулирование выводов.

## Основные результаты

Анализ позволил оценить изменение уровня заработной платы по регионам России за рассматриваемый период, сравнить распределение региональных показателей и выделить субъекты с наиболее высокими значениями заработной платы.

В частности, были выявлены изменения средних и медианных значений, а также показателей разброса заработной платы между регионами. Дополнительно составлены рейтинги десяти регионов с наиболее высокой заработной платой за 2022 и 2023 годы.

## Основные выводы

В 2023 году среднемесячная номинальная заработная плата увеличилась во всех основных статистических показателях по сравнению с 2022 годом: выросли среднее значение и медиана, а также минимальный и максимальный уровни заработной платы. При этом увеличение стандартного отклонения и размаха свидетельствует о расширении абсолютного разброса зарплат между регионами. Рейтинг наиболее высокооплачиваемых субъектов показал, что лидирующие позиции в оба года занимали преимущественно северные и удалённые регионы, а также Москва. Таким образом, несмотря на общий рост номинальной заработной платы, существенные различия в её уровне между регионами сохраняются.

## Структура проекта

- `иннополис__Пашов_Илья (2).ipynb` — основной файл с кодом, расчётами, результатами и аналитическими выводами.
- `my_date_2022.csv` — исходные статистические данные за 2022 год.
- `my_date_2023.csv` — исходные статистические данные за 2023 год.

При выполнении ноутбука дополнительно формируется файл `results.txt` с результатами расчётов и итоговыми выводами.

## Запуск проекта

Файл analysis.ipynb можно просмотреть непосредственно на GitHub вместе с кодом и результатами анализа.

Для повторного выполнения расчётов необходимо скачать репозиторий, установить Python и Jupyter Notebook, открыть ноутбук и выполнить все ячейки. Исходные CSV-файлы должны находиться в одной папке с ноутбуком.

Дополнительные библиотеки Python не требуются.
